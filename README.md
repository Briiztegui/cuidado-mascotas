# cuidado-mascotas
Proyecto 3- Media Pila
Huellitas

Huellitas es una plataforma que conecta dueños de mascotas con profesionales especializados en cuidado animal.

Los usuarios pueden registrarse como:

Cliente
Buscar profesionales.
Filtrar por categoría.
Solicitar servicios.
Dejar reseñas luego de una contratación completada.
Oferente
Crear perfil profesional.
Publicar servicios.
Gestionar solicitudes.
Visualizar estadísticas y reseñas.
Acceso y registro

El sistema permite el registro mediante nombre, correo electrónico, contraseña y selección de rol. El rol elegido durante el registro es permanente y determina las funcionalidades disponibles para cada usuario.
